# Problem sets

By hand, timed, no notes open.

## Rules

1. Attempt the whole thing before looking at anything. The OCW answer keys are there, and using them early is the biggest way to waste this course.
2. Keep the wrong attempts. Don't tidy up before committing. The visible false starts are worth more than the clean final page.
3. Log every error in [`../error-log.md`](../error-log.md) with a cause.
4. On a retry, write a fresh attempt instead of editing the old one, and commit it as `retry`.

## Layout

```
ps/unit-1/problem-set-1.md
ps/exam-1/
```

- `ps/unit-N/` for unit problem sets
- `ps/exam-N/` for unit exams, with the exam PDF, my solutions, and my self grading notes

## Committing an exam

In this order, because it reads as an honest progression:

1. `exam-1: my solutions`
2. `exam-1: self graded against key`, adding what I missed and why
3. `exam-1: corrections after review`
