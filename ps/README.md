# Problem sets

Worked **by hand, timed, with no notes open.**

## Rules

1. Attempt first, fully, before looking at anything. The OCW answer keys are
   there; using them before attempting is the single biggest way to waste this
   course.
2. **Keep wrong attempts.** Don't clean them up before committing. The
   visible false starts are worth more than the tidy final page — they're
   what makes the commit history readable.
3. Log every error in [`../error-log.md`](../error-log.md) with a root cause.
4. On a retry, write a fresh attempt rather than editing the old one, and
   commit it as `retry`.

## Layout

```
ps/unit-1/problem-set-1.md
ps/exam-1/
```

- `ps/unit-N/` — unit problem sets
- `ps/exam-N/` — unit exams, including the exam PDF, my solutions, and my
  self-grading notes

## Committing an exam

After an exam, commit in this order — it reads as a clean progression:

1. `exam-1: my solutions`
2. `exam-1: self-graded against key` (add what I missed and why)
3. `exam-1: corrections after review`
