# Error log

Every first-attempt mistake, with a root cause. This file is the point of the
whole repo — it is what makes progression legible instead of just visible.

**Rules**

- Log it *even if the final answer was right*. Right answer / wrong method is
  the most expensive mistake and the easiest to hide.
- One line for the root cause, not a description of the error. "Used the chain
  rule twice and never simplified" — not "made an algebra mistake".
- Re-read weekly. Mark entries fixed. A repeat means the root cause was never
  actually addressed.
